# TerraSandbox · 泰拉瑞亚式 2D 沙盒生存

纯 **HTML5 Canvas + 原生 JavaScript** 实现的侧视沙盒生存游戏，**零第三方依赖**，双击 `index.html` 即可开玩。

## 玩法

随机生成的丘陵地形，向下挖能遇到洞穴与煤/铁/金三层矿脉。挖到的材料进背包，可以合成木板、工作台、火把和四档镐/剑。放置工作台后靠近它才能合成高级装备。白天安全，入夜后僵尸从两侧逼近，用剑击杀可掉金币，天亮后僵尸自燃消失。

## 操作

| 按键 | 功能 |
| --- | --- |
| A / D | 左右移动 |
| 空格 / W | 跳跃 |
| 鼠标左键 | 持镐挖掘 · 持方块放置 · 持剑攻击 |
| 1 ~ 0 / 滚轮 | 切换快捷栏 |
| E / Tab | 打开合成面板 |
| H | 帮助 · Esc 关闭 |

## 已实现特性

- **随机地形**：1D 分形噪声定地表起伏（落差约 ±20 格），2D 噪声掏洞穴，随机游走生成三种矿脉，概率种树
- **13 种图块**：空气、草地、泥土、石块、煤矿、铁矿、金矿、树干、树叶、木板、工作台、火把、基岩
- **挖掘与建造**：镐子分四级（木→石→铁→金），硬度与所需镐等级写在数据表里；方块放置需相邻支撑（火把除外）
- **合成系统**：木板 / 工作台 / 火把 / 四档镐 / 四档剑，高级配方需靠近工作台
- **AABB 物理**：与图块网格碰撞，先 X 后 Y 分轴解算，支持跳跃、落地判定、遇墙停止
- **昼夜系统**：余弦曲线驱动天色与亮度，日月沿轨道起落，夜间显示星空
- **僵尸 AI**：夜间在屏幕外生成，朝玩家移动，被墙挡住会起跳，接触造成伤害，天亮自燃消失，击杀掉落金币
- **光照系统**：天空光按深度衰减 + 火把半径光晕 + 玩家自身微光，逐格叠加暗色遮罩
- **HUD**：10 颗红心生命条、10 格快捷栏（含数量与快捷键编号）、金币、天数与昼夜状态

## 运行

```bash
# 方式一：直接双击 index.html
# 方式二：本地起服务（推荐，避免个别浏览器的本地文件策略）
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

## 代码导览

| 模块 | 位置 | 关键思路 |
| --- | --- | --- |
| 常量与图块 | `T` / `TILEINFO` / `ITEM` | 数据驱动，加新方块只需加表项 |
| 噪声 | `hash1` / `hash2` / `noise1` / `noise2` / `fbm` | `Math.imul` 保证 32 位整数乘法不丢精度，哈希 → 平滑插值 → 分形叠加 |
| 世界生成 | `createWorld` / `veins` | 1D 定地表 → 2D 掏洞 → 随机游走画矿脉 → 概率种树 |
| 物理 | `collides` / `moveEntity` | AABB 与图块网格，分轴解算避免穿模 |
| 交互 | `handleMouse` | 手持物决定左键行为：镐挖、块放、剑砍 |
| 僵尸 | `spawnZombie` / `updateZombies` | 夜间限流生成、追踪、越障跳跃、白天自燃 |
| 光照 | `drawDarkness` | 天空光按深度衰减，叠加火把与玩家点光源 |
| 渲染 | `drawTile` / `drawHumanoid` / `drawHUD` | 哈希驱动伪随机纹理像素，矩形拼装角色 |
| 合成 | `RECIPES` / `canCraft` / `craft` | 配方表 + 材料检查 + 工作台邻近检测 |
| 主循环 | `loop` | 固定 60Hz 时间步 + 累加器，渲染与逻辑解耦 |
